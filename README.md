# Path Hunter: ทลายลิมิตพิชิตจุดกำเนิด

มินิเกมฝึก **การทดสอบสองเส้นทาง (Two-Path Test)** สำหรับลิมิตของฟังก์ชันหลายตัวแปร (แคลคูลัส 2)

## วิธีเล่น
- เลือกการ์ดเส้นทาง 2 ใบ (C₁, C₂) ที่ทำให้ค่าลิมิต L₁ ≠ L₂ เพื่อพิสูจน์ว่าลิมิตไม่มีค่า
- เลือกเส้นโค้งที่ทำให้พจน์ในตัวส่วนมีดีกรีเท่ากัน รับโบนัส **Degree Matcher x2**
- ในตอน ง มีโจทย์ที่ลิมิตมีค่าจริง ให้ใช้ **Squeeze Shield** แล้วเลือกเหตุผลที่ถูกต้อง

มีทั้งหมด 18 ด่าน แบ่งเป็น 4 Tier: เส้นตรง, เส้นโค้ง, สามตัวแปร และโจทย์ท้าทาย
